# Диагностика распознавания голосовой команды

## Цель

Показать в WPF фактический текст, который Whisper распознал после слова активации, независимо от прохождения порога confidence. Это нужно только для проверки контура `микрофон → VAD → Whisper`; поведение resolver и исполнение аудиокоманд не меняются.

## Поведение

- При непустом результате Whisper поле «Последняя команда» показывает фактический распознанный текст.
- Поле «Результат» показывает `Распознано, confidence: 0.42` с фактическим значением confidence.
- Текст с confidence ниже текущего порога не передаётся в resolver и не исполняется.
- Если VAD не обнаружил речь или Whisper не вернул текста, поле «Результат» показывает `Команда не распознана`.
- После диагностического результата конвейер сохраняет существующее восстановление через cooldown и снова ожидает слово активации.

## Контракты и поток данных

`SpeechRecognitionException` для низкой уверенности получает безопасные диагностические поля: распознанный текст и confidence. `WhisperCppSpeechToTextProvider` заполняет их перед выбросом типизированной ошибки. `VoicePipelineCoordinator` переносит эти поля в `VoicePipelineSnapshot`, не отправляя текст в `ICommandDispatcher`. `VoiceControlViewModel` формирует русское диагностическое сообщение для существующих полей UI.

Для отсутствия речи coordinator публикует стабильный код `speech-not-detected` и безопасное сообщение `Команда не распознана` до перехода в cooldown.

## Безопасность

- Распознанный текст отображается только в локальном UI и не записывается в журнал.
- Аргументы команд, endpoint ID, пути моделей и внутренние исключения не добавляются в snapshot или сообщения.
- Низкоуверенный текст никогда не исполняется.
- Аудио остаётся только в памяти и очищается существующим контуром.

## Проверка

- Unit-тест провайдера подтверждает сохранение текста и confidence в типизированной ошибке низкой уверенности.
- Тест coordinator подтверждает публикацию диагностического текста без вызова сервиса команд.
- Тест ViewModel проверяет оба формата: распознанный текст с confidence и `Команда не распознана`.
- Полный набор тестов, Release build и format gate должны остаться зелёными.
