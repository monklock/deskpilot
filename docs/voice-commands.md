# Голосовые команды управления звуком

Milestone 3 выполняет только конечный доверенный набор локальных русских команд. Распознанный текст не превращается в произвольную команду: модуль публикует разрешённые шаблоны, каталог проверяет наличие обработчика, а resolver создаёт типизированный `CommandRequest`.

## Поддерживаемые команды

| Команда | Канонические фразы | Действие |
|---|---|---|
| `audio.switch-preferred-device` | `переключи на наушники`, `включи наушники`, `звук на наушники` | Переключает вывод на сохранённые наушники. |
| `audio.switch-preferred-device` | `переключи на колонки`, `включи колонки`, `звук на колонки` | Переключает вывод на сохранённые колонки. |
| `audio.toggle-preferred-device` | `переключи устройство`, `переключи звук между устройствами` | Переключает вывод между сохранёнными наушниками и колонками. |
| `audio.change-volume` | `сделай громче`, `громче`, `увеличь громкость` | Увеличивает громкость ровно на 10 процентных пунктов с ограничением до 100. |
| `audio.change-volume` | `сделай тише`, `тише`, `уменьши громкость` | Уменьшает громкость ровно на 10 процентных пунктов с ограничением до 0. |
| `audio.set-volume` | `громкость {percentage}`, `установи громкость {percentage}`, `сделай громкость {percentage} процентов` | Устанавливает громкость в диапазоне `0..100`. |
| `audio.set-mute` | `выключи звук`, `убери звук`, `без звука` | Выключает звук. |
| `audio.set-mute` | `включи звук`, `верни звук` | Включает звук. |
| `audio.toggle-mute` | `переключи мьют`, `переключи беззвучный режим` | Переключает текущее состояние mute. |

`{percentage}` принимает цифры или русское количественное числительное от нуля до ста. Допустимы формы `процент`, `процента`, `процентов`. Примеры: `громкость 45`, `установи громкость сорок пять процентов`, `сделай громкость сто процентов`.

## Сопоставление

1. Текст локально нормализуется: регистр, пунктуация, лишние пробелы и различие `ё/е` не влияют на точное совпадение.
2. Сначала выполняется полное точное сопоставление.
3. Только при отсутствии точного результата разрешается ограниченное нечёткое сопоставление с порогом `0.86` и запасом неоднозначности `0.08`.
4. Процент всегда разбирается строго. Нечёткий resolver не угадывает, не исправляет и не подменяет число.
5. Неизвестная или неоднозначная фраза не передаётся в `ICommandDispatcher` и не меняет состояние звука.

## Устройства и безопасность

- Наушники и колонки должны быть заранее сохранены в интерфейсе по стабильному Windows endpoint ID.
- Переключение выполняется только на запрошенное сохранённое и доступное устройство. Подстановка другого endpoint запрещена.
- Команда переключения между устройствами отклоняется, если текущее устройство не входит в сохранённую пару.
- Bluetooth-подключением управляет Windows; DeskPilot не выполняет pairing или reconnect.
- Vosk, Whisper, нормализация и разрешение команд работают локально. Аудио не сохраняется и не передаётся по сети.
- UI и журналы получают только безопасные поля: ID команды, статусы, confidence и стабильный код ошибки. Распознанный текст не пишется в журнал; endpoint ID, аргументы, пути и внутренние сообщения обработчиков не публикуются.
